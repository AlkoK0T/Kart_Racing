## CR-02 — выполнен, коммит 302a1c4

- Пустые массивы кругов сохраняются; фиктивный круг 0 не создаётся.

  Обращения к несуществующим элементам массивов исключены.
- Добавлены регрессии нормализации, первого круга, YAML, TCP, API и веб-рендера;
  шаблоны проверены с StrictUndefined. Неиспользуемое отладочное выражение в

- Добавлены шесть Behave-сценариев; README описывает семантику пустого результата.

## CR-03 — выполнен, коммит подтверждён пользователем

Изменения:

- Общий DataIngestor проверяет внешние снимки до записи в store. Один экземпляр
  подключён в run.py к файловому источнику, TCP и универсальному RS-232.
- Расчёт гонки вынесен в karting/domain.py; старый импорт normalize_race оставлен
  совместимым. Для YAML выделен режим старых форматов, для JSON — строгий контракт.
- Проверяются обязательные поля, версия 1, состояния, участники и совпадение ключей
  с laps, положительные конечные времена, полные рекорды children/women/men.
  Пустые круги и null-рекорды допустимы. Необязательные даты/метки проверяются,
  если присутствуют; date/month остаются необязательными для старых отправителей.
- Проверяются UTF-8, повторяющиеся ключи, конечность чисел, циклы YAML,
  размеры строк/дерева/коллекций и количество участников/кругов. YAML использует
  безопасный loader. Новые категории требуют явной регистрации валидатора.
- При ошибке валидации снимок, ревизия и события не меняются. TCP возвращает
  ok:false с field/причиной и принимает следующий корректный пакет. Слишком
  длинная строка закрывает TCP-соединение. RS-232 отбрасывает неверные строки,
  сохраняет фрагменты при таймаутах и не принимает хвост превышенного сообщения.
- Добавлены 33 unit-теста и 13 Behave-сценариев, обновлены README,
  ARCHITECTURE и interface.md (ранее не отслеживался Git).

Проверено 2026-10-10:

$env:LOG_FILE=''

Результат: 57 unit-тестов успешно (включая запуск 12 JS-тестов), отдельный тест

TCP использует loopback и свободные порты, YAML — временные каталоги,

Сообщение коммита CR-03:

CR-03: Проверять входные снимки перед записью в хранилище

Добавлен общий слой валидации файлов, TCP и RS-232 с отдельной совместимостью

## CR-05 — выполнен

Автодетект, открытие и инициализация ODTEMP находятся в одном цикле восстановления.
Ошибки ОС/порта повторяют полную попытку через stop-event с интервалом 60 секунд;
ручной порт не зависит от перечисления USB. source.odtemp отражает starting,
reconnecting, waiting_measurement, online, stopped и failed. Неожиданная ошибка
останавливает retry с ERROR и диагностикой failed, а не маскируется бесконечно.
Первое новое измерение, а не открытие порта, подтверждает восстановление.
Пять регрессий проверяют сбой перечисления, смену COM, stop во время retry,
ручной порт и программную ошибку на подменённых устройствах/ожиданиях.
