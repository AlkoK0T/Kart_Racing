# Исправления по CODE_REVIEW.md

Работа выполняется по одному пункту. После подготовки изменений и проверки
коммит ожидает подтверждения пользователя; следующий пункт до этого не начинается.

## CR-01 — выполнен, коммит 1b92c85

Изменения:

- Общий контроллер `app/static/js/polling.js` вместо трёх копий JavaScript.
- HTML передаёт через JSON ревизию отрисованного снимка, веб-подвид и интервал.
- Polling с `category=current_race` не считает обновления часов/температуры
  изменением таблицы. API без category сохраняет прежнюю семантику.
- Подключение контроллера в обоих вариантах кругов, гонке и универсальной таблице.
- Удалены неопределённая переменная `сurrent_race.UPD_TIME` и чтение отсутствующего
  timestamp. Подвид сравнивается с style1/style2, а не именем шаблона race.
- `PUT /state` допускает только style1/style2.
- Единственная отложенная перезагрузка, отсутствие параллельных запросов внутри
  одного цикла, timeout/backoff, отмена при уходе и восстановление при pageshow.
- Добавлены Flask/unit, исполняемые JS-регрессии и четыре Behave-сценария.

Проверено 2026-10-10:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
$env:LOG_FILE=''
.\.venv\Scripts\python.exe -m behave --format progress
```

Результат: 13 unit-тестов успешно (включая запуск 12 JS-тестов в Node.js);
7 features, 48 сценариев, 187 Behave-шагов успешно. JS проверялся с подменёнными
DOM/fetch/таймерами; настоящий браузер и работающий производственный сервер не
запускались.

Коммит подтверждён пользователем и создан с русским описанием:
`1b92c85` — «CR-01: Исправить обновление веб-индикации».

## CR-02 — подготовлен, ожидает подтверждения коммита

Изменения:

- Пустые массивы кругов сохраняются; фиктивный круг 0 не создаётся.
- Число кругов равно 0; отсутствующие времена, позиция и отставание — None
  (`null` в API). Участник без круга не получает лидерство.
- Ранжируются только реальные результаты, участники без результатов идут после
  них. Сохранено ранжирование по лучшему кругу, не введены другие правила гонки.
- DIFF вычисляется только при двух кругах; настоящий ноль не подменяется прочерком.
- Все три веб-вида используют общие макросы форматирования отсутствующих значений.
  Обращения к несуществующим элементам массивов исключены.
- Добавлены регрессии нормализации, первого круга, YAML, TCP, API и веб-рендера;
  шаблоны проверены с StrictUndefined. Неиспользуемое отладочное выражение в
  HTML-комментарии заменено невыполняемым комментарием Jinja.
- Добавлены шесть Behave-сценариев; README описывает семантику пустого результата.

Проверено 2026-10-10:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest -v test_tcp_race_contract.py
$env:LOG_FILE=''
.\.venv\Scripts\python.exe -m behave --format progress
```

Результат: 24 unit-теста успешно (включая запуск 12 JS-тестов);
отдельный тест TCP-контракта успешно; 8 features, 54 сценария, 212 Behave-шагов
успешно. TCP проверен на свободном loopback-порту, YAML — во временном каталоге;
реальное оборудование, GUI-окна и браузер не запускались.

Сообщение подготовленного коммита:

```text
CR-02: Исключить фиктивные результаты участников без кругов

Пустые массивы кругов сохраняются, число кругов равно нулю, отсутствующие времена
и позиции передаются как null. Участники без результата не становятся лидерами
и отображаются после участников с завершёнными кругами. Первый круг учитывается
без фиктивного нулевого, DIFF вычисляется только после двух кругов.

Все веб-виды показывают отсутствующие результаты прочерками. Добавлены unit-
и Behave-регрессии для начала гонки, первого круга, YAML/TCP/API и отображения;
обновлена документация.
```
