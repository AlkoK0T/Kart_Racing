# Приёмка на целевом Windows-ПК

Обычная безопасная команда: `.\.venv\Scripts\python.exe run_tests.py`.
Она не открывает USB и нативные окна. Unit включает корневой TCP-контракт и
12 JS-регрессий через Node.js; далее запускается весь Behave. Ошибки cleanup —
ошибки hook, а не молча проигнорированные исключения. Исходный failed step сохраняется.

Ниже только явные opt-in проверки. В этой сессии они не запускались. Не запускайте
аппаратный smoke одновременно с run.py: он открывает тот же термометр. Скрипт
выполняет ~I/~F и при необходимости ~W, как основной модуль.

## Три настоящих SDL2-окна и нагрузка

```powershell
.\.venv\Scripts\python.exe smoke_test.py --sdl --seconds 60
```

Проверить три окна с координатами и размерами из screens.yaml, чередование верхних
видов, нижних сообщений и GIF. Закрытие окна во время smoke считается отказом.
После завершения должны закрыться все окна и worker. В выводе: health, elapsed,
CPU seconds и Python traced peak bytes. Последнее НЕ общий RSS/видеопамять.
В Диспетчере задач записать CPU%, рабочий набор и дескрипторы после прогрева,
через 10/30/60 минут с реальными GIF; повторить при INFO/DEBUG и выбранных FPS.
Критерий: нет роста после прогрева, отсутствуют повторные неизменные texture uploads;
допустимую CPU-нагрузку зафиксировать для конкретного ПК, не переносить цифры модели.
Повторить start/stop 10 раз. Частичные отказы второго окна/renderer/texture
автоматически проверены подменами в unit; аппаратный отказ драйвера не моделировался.

## USB ODTEMP и смена COM

```powershell
.\.venv\Scripts\python.exe com_port_inventory.py
.\.venv\Scripts\python.exe smoke_test.py --odtemp --serial-number YOUR_SERIAL --seconds 360 --log-level DEBUG
```

Вместо YOUR_SERIAL указать реальный serial из отчёта; без него hardware smoke запрещён.
Измерение должно прийти до завершения. Во время теста отключить/подключить USB,
в том числе в другой разъём. Проверить WARNING connection lost, INFO retry,
повторное определение и инициализацию, единственное INFO reading restored после
нового измерения (не только после успешного open). Отдельно прекратить выдачу
показаний без отключения: через 120 секунд quality=stale, каждые 60 секунд retry;
после возобновления good. Для просмотра API/экранов повторить с основным run.py,
а не одновременно со smoke. Выключение модуля прекращает попытки.

Инвентаризацию составных USB-интерфейсов и миграцию CSV сначала выполнять с
отдельной тестовой копией реестра. Проверить AMBIGUOUS при одинаковых ID и MOVED
при смене COM. Программные тесты не доказывают наличие уникального serial у платы.

## Настоящий браузер

Необязательный Playwright/Chromium должен быть установлен отдельно:

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe smoke_test.py --browser
```

Скрипт поднимает только локальный временный Flask-сервер без оборудования, проверяет
исполнение polling без JS-ошибок, отсутствие reload при температуре и ровно один
reload при смене вида/гонки. Сервер и Chromium закрываются после теста.
На втором физическом мониторе отдельно проверить fullscreen браузера, обе таблицы,
нулевые круги и восстановление polling после прерывания сети/возврата со страницы.
Node-регрессии не заменяют проверку браузера, драйвера или монитора.

## Delphi 7

Инструкция opt-in компиляции и TCP/null/UTF-8/deadline/cancel:
[delphi/README.md](delphi/README.md). Нужен лицензированный Delphi 7 dcc32.
В найденном Embarcadero 23.0 CLI-сборка запрещена лицензией, результат сборки
не подтверждён. До аппаратной приёмки отдельно проверить Form submit при
недоступном сервере, обновление ожидающего снимка и закрытие формы во время отправки.
